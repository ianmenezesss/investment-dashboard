## Gates técnicos e operacionais

- [ ] `main` contém o commit revisado; árvore limpa; PR/checks aprovados.
- [x] Frontend no candidato: 217 testes em 28 arquivos, `npm run build` aprovado e `npm audit` sem vulnerabilidades conhecidas (verificações executadas nesta revisão; árvore de dependências atual).
- [x] Backend no candidato: 382 aprovados, 1 ignorado (integração PostgreSQL opt-in) e 1 aviso de depreciação Starlette `TestClient`/httpx; executado em container Python 3.12 descartável com código somente leitura.
- [x] PostgreSQL descartável: cadeia 001–009 e ensaio sintético de backup/restauração aprovados, com eventos, fingerprints/contagens, RLS/FORCE RLS, policies, grants e isolamento entre proprietários. Dados fictícios; nenhuma conexão de produção.
- [ ] Estado esperado da migration e compatibilidade do schema foram confirmados em procedimento de leitura. Nenhuma migration de produção sem aprovação explícita.
- [x] Um único backup manual do schema `public` foi gerado após autorização fora do repositório; tamanho e SHA-256 foram recalculados e coincidiram com o registro do proprietário. Não há agendamento nem cópias de retenção adicionais.
- [ ] Confirmar que a frase desse backup foi guardada separadamente em meio protegido; não registrar a frase no projeto.
- [ ] Ensaiar a restauração do arquivo real somente em PostgreSQL descartável. O round-trip com dados fictícios passou; o ensaio do arquivo real aguarda autorização específica para inserir a frase localmente.
- [ ] Health Render responde; versão/commit do serviço hospedado corresponde ao release aprovado.
- [ ] Variáveis Vercel/Render/Supabase conferidas sem revelar valores; HTTPS, CORS e CSP correspondem a cada domínio.
- [ ] Logs/alertas não registram tokens, senhas, URLs SQL ou payloads financeiros; procedimento de resposta/rollback está disponível.

As verificações ainda desmarcadas refletem validações não executadas ou não confirmadas; não foram convertidas em aprovações por inferência. Para uma release de portfólio sem mudança de schema ou de dados de produção, a restauração do artefato real e a inspeção detalhada de Network/CSP são riscos operacionais residuais, não bloqueios técnicos demonstrados: o hash do único arquivo confere, o round-trip sintético passou, a demo foi confirmada pelo proprietário e os testes automatizados exercitam o isolamento. Manter essas limitações explícitas e não anunciar o backup como restaurabilidade comprovada.
